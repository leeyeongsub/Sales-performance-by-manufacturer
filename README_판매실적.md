# 📊 제조사별 판매실적 조회 시스템

**제조사별 판매실적 조회** 시스템은 다양한 제조사의 제품 판매 데이터를 실시간으로 조회하고 분석할 수 있는 내부 비즈니스 도구입니다.  
간결한 인터페이스와 정확한 데이터 필터링 기능을 통해 **전략적인 의사결정**을 지원합니다.

---

## 📌 주요 기능

- 제조사별 판매실적 조회 (일/월/연 단위)
- 제품군별 필터링 및 정렬
- 기간별 매출 추이 시각화
- 테이블 및 그래프 기반 실적 보고
- 엑셀 다운로드 기능

---

## 🖥 사용 기술 스택

| 분류       | 기술 |
|------------|------|
| 프론트엔드 | HTML, CSS, JavaScript (또는 React) |
| 백엔드     | Node.js / Python / Java (선택에 따라) |
| 데이터베이스 | MySQL / PostgreSQL 등 |
| 데이터 시각화 | Chart.js, D3.js 등 |
| 배포환경   | 내부망 or AWS / Azure |

---

## 🧩 시스템 흐름

1. 사용자 로그인
2. 제조사 및 기간 선택
3. 실적 데이터 조회 및 그래프 표시
4. 보고서 출력 또는 엑셀 다운로드
